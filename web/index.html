Board shortcuts and ranking

Ranking

  • Fastest shows each person's accepted run with the lowest CPU time. Ties go to lower memory, then the earlier submission.
  • Leanest shows each person's accepted run with the lowest peak memory. Ties go to lower CPU time, then the earlier submission.
  • Tries counts every submission for that problem in this round, including rejected ones.
  • A frozen board hides submissions made after the freeze. Everything appears when the round ends.

Reading the signal

On Fastest, more pulses means a faster run: half the speed of the leader draws half the pulses. Hz is one divided by the CPU time. On Leanest, fewer lit blocks means less memory.
